# Preview 0.3 本地流式语音验证

## 已通过

- TypeScript 检查、构建、git diff --check。
- Paraformer INT8 + CT-Transformer 在私有 Node/sherpa-onnx 原生进程上运行，无 Python/CUDA。
- 官方示例 WAV（10.053 秒）分块识别返回 12 次临时结果，并返回带中文标点的最终句子。
- 当前机器一次测量：冷加载 1124ms，全部音频分块解码与收尾 339ms。这是加速文件回放测量，不是端到端麦克风延迟，也不代表低配机器。
- 错误采样、失效会话、重复启动、静音 48kHz、取消、原生进程被终止后的重新启动。
- Chromium 模拟麦克风回放真实录音，经 AudioWorklet、IPC、标准输入输出、原生识别，显示部分结果并追加到输入框。
- 原有草稿保留、句子追加顺序、停止收尾、取消、启动中取消、切换会话不串写。
- 最终打包程序 UI 语音测试通过；截图见 src/dist/preview/speech-input.png。
- 真实 NSIS 安装后语音测试通过，安装路径包含中文和空格。
- 同版本覆盖安装、普通卸载保留数据、彻底卸载清理、注册入口清理、用户/系统 PATH 不变。最后仅调整状态区布局并重打包，最终包再次通过打包程序语音 UI 测试。
- 原有 Codex 四项配置、exec/app-server 首次与恢复调用回归通过。
- 原版 Conductor 四个 Electron 进程保持运行，原工作区未修改；测试 Preview 安装已卸载。

## 未验证

- 真人麦克风、口音、噪声环境和专业词汇准确率；示例中的中英文/数字已有错字，需用户实际试用，不能宣称达到某准确率。
- macOS/Linux 仅完成平台路径、原生组件选择、动态库环境、构建入口与 macOS 权限配置，尚未在这些系统构建或运行。
- 干净 Windows 虚拟机、非管理员账户的所有设备权限组合、签名、公证、跨版本数据迁移尚待验收。
